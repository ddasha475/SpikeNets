# SpikeNets: Бинарная классификация интенсивности пуассоновского потока спайковым нейроном (TTFS)

Репозиторий содержит реализацию спайковой нейронной сети на базе модели **ExpNeuron** для решения задачи бинарной классификации интенсивности входного пуассоновского потока $\lambda$ относительно порогового барьера $\Lambda$ с использованием **декодирования по первому спайку (Time-To-First-Spike, TTFS)**.

Обучение синаптических весов $w$ выполняется аналитическим методом на основе точной дифференцируемой вероятности первого пересечения барьера (факторизация Винера–Хопфа + численное обращение преобразования Лапласа методом Гавера–Стефеста 14-го порядка).

## 🚀 Воспроизведение экспериментов

1. Установка зависимостей:
```bash
pip install -r requirements.txt
```

2. Запуск полного пакета экспериментов:
```bash
python experiments/run_experiments.py
```
Скрипт выполнит обучение, снимет метрики для всех свипов гиперпараметров ($\beta$, $T$, $x$, $\Lambda$, $\sigma$), проведет Multi-Run сравнение с baseline моделью LIF и обновит графики в директории `experiments/plots/`.

---

## 📊 Основные результаты

* **ExpNeuron (соревновательный TTFS)**: точность **$95.30\% \pm 1.08\%$** на 10 независимых тестовых прогонах (в сравнении с $94.70\% \pm 1.35\%$ у стандартного LIF).
* **Одиночный нейрон с калиброванным TTFS $\tau^*$**: точность **$95.5\%$** (при $\beta = 0.02, T = 200$).
* **Оптимальный диапазон утечки мембраны**: $\beta \in [0.01, 0.02]$.
* **Минимальный горизонт наблюдения**: $T \ge 200$ шагов для преодоления пуассоновского предела неопределенности.
